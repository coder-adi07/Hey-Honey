# 🍯 Hey Honey — Artisanal American Honey E-Commerce

## 🌟 Highlights & Features

- **🐝 Interactive 3D Honeybee Hero (`Three.js`)**: Real-time canvas model featuring 60fps wing oscillations, glowing pollen particle clouds, and interactive mouse-tracking flight paths.
- **✨ Editorial Artisanal Aesthetic**: Designed around warm cream (`#F8F4EB`), honey amber (`#C58A32`), golden honey (`#E5B34F`), and deep espresso typography matching the original brand heritage.
- **🛍️ Complete E-Commerce Suite**:
  - Full catalog filtering across all 5 authentic categories (Raw, Filtered, Flavored, Rare Imports, Beeswax).
  - Dynamic slide-in Cart Drawer with live \$50 free shipping progress bar, quantity controls, and subtotal calculation.
  - Interactive live Search Modal across all products and categories.
  - Interactive Honey Pairing Guide (cheeses, teas, savories, desserts).
  - "Find Your Honey Match" flavor quiz modal.
- **📖 The Hive (Editorial Journal)**: Authentic articles by Jay Jermo detailing honey bee biology, blueberry pollination, enzymes, and modern beekeeping challenges.
- **📍 Real Heritage & Farmers Market Schedule**: Michigan market locations (Ann Arbor Kerrytown, Detroit Eastern Market, etc.) with verified business contact info.
- **📱 Responsive & Accessible**: Mobile-first drawer navigation with collapsible category menus, accessible focus states, and smooth hover micro-interactions.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router — pure JavaScript ES6+)
- **Styling**: Tailwind CSS with custom palette and Google Fonts (`Open Sans Condensed` + `Source Sans 3`)
- **3D Graphics**: Three.js
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/coder-adi07/Hey-Honey.git
cd Hey-Honey
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
